# 广告去哪找？怎么接进来？

## 一句话结论

小程序里的广告**只有一个正规来源：微信自己的「流量主」**。
穿山甲、优量汇、AdMob 这些第三方广告联盟**都不支持小程序**（它们是给 App 用的），
硬塞进去的 SDK 既跑不起来，也违反平台规则，属于会被封号的操作。所以「去哪里找广告」
= 「怎么开通流量主」。

---

## 为什么不能在部署前就把广告接好

不是代码没接好，是**广告位 ID 必须等流量主开通后才有**，而流量主的门槛是流量：

| 步骤 | 谁能做 | 什么时候 |
| --- | --- | --- |
| 代码接入（看广告 → 送次数 → 埋点） | 已经做完了 | 现在 ✅ |
| 开通流量主 | 公众平台「流量主」入口申请 | 累计独立访客（UV）达标后，**一般要求 ≥ 1000**，以后台实际显示为准 |
| 创建广告位拿 `adunit-xxx` | 流量主后台「广告位管理」 | 开通之后 |
| 把 `adunit-xxx` 填进服务端 | 云托管控制台 → 环境变量 `AD_UNIT_REWARDED` | 拿到之后，重新发布即可，**不用重新提审** |

所以正常顺序是：**先上线 → 攒到 1000 UV → 开通流量主 → 填广告位**。

> 没填广告位之前，程序不会卡住用户：激励视频放不出来就**直接放行保存**，
> 同时记一条 `ad_fail_open` 埋点。你在看板上看到这个数一直涨，就说明「该去开流量主了」。

---

## 开通与配置路径（照着点）

1. 登录 <https://mp.weixin.qq.com> → 左侧「流量主」（没到门槛时这里是灰色的，会显示还差多少 UV）
2. 开通后进「广告位管理」→ 新建广告位 → 类型选 **激励视频**，另外可以顺手建 **banner** 和 **插屏**
3. 每个广告位会拿到一串 `adunit-xxxxxxxxxxxxxxxx`
4. 打开「微信云托管控制台 → 你的服务 → 服务设置 → 环境变量」，逐个填：

| 环境变量 | 填什么 |
| --- | --- |
| `AD_UNIT_REWARDED` | 激励视频广告位 ID（**最重要**，用户点保存时弹的就是它） |
| `AD_UNIT_BANNER_HOME` | 首页底部 banner |
| `AD_UNIT_BANNER_RESULT` | 结果页底部 banner |
| `AD_UNIT_INTERSTITIAL` | 插屏广告 |

5. 保存后**重新发布**一次服务，用户无感切换（这就是把广告位放服务端的好处）

> 也可以直接把 ID 写进 `miniprogram/config/index.js` 的 `adUnits`，但那样每次改都要重新提交审核，
> 而且审核要等几天 —— 不推荐。

## 收益怎么算、钱怎么拿到

- 结算口径以「公众平台 → 流量主 → 数据」为准，自建埋点（`ad_show` / `ad_click` / `ad_reward_success`）用来和业务漏斗对齐，两边对不上时信官方。
- 收益会先记在流量主账户里，达到起提门槛（一般 100 元）才能提现，具体规则以后台「结算」页为准。
- 影响收益的主要是**曝光量**和**完播率**：激励视频要用户完整看完才算有效，所以「看一次 +10 次」这种
  明确的好处比弹窗硬广转化高得多 —— 这也是当前这套规则的设计原因。

## 攒第一批 1000 UV 的常见办法

- 分享卡片做得好一点：标题写清「粘贴链接就能存原片」，别写「破解」「神器」这类会被驳回的词
- 微信群 / 朋友圈先跑一轮，看板上看 `new_user_from_share`（分享带来的新用户）验证效果
- 小红书 / 贴吧 / 抖音评论区导流（注意别直接放二维码，容易被限流）
- 小程序后台「搜索」里优化关键词：「去水印」「视频保存」这类词的自然流量很可观

---

## 其他变现方式（先知道有这回事）

- **会员/买次数**：需要企业主体才能开微信支付，个人主体做不到，所以前期只能靠广告。
- **流量主之外不用折腾别的**：任何让你「接第三方广告 SDK」的说法，对小程序的合规风险都很高。
- ⚠️ 别用其他平台的官方 logo 做图标、别写「免费下载别人的作品」，这是商标和版权风险，
  和广告没关系，但会直接导致封号。
